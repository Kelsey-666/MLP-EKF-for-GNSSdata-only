# PedestrianKalmanFilter

MATLAB Kalman filter used to process pedestrian GNSS data using pseudorange and Doppler measurements.

## Getting started

Use the `Run.m` script to run the Kalman filter where the paths must be set for the `addpath` and `dir` commands at the start of the script. The script expects a folder with *_gnss.mat files containing `gnss` measurements and `rov_truth` truth information.
